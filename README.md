# JarvisOS

A fully autonomous AI assistant built from scratch.

## Vision

JarvisOS is a local AI assistant capable of:

- Natural conversation
- Voice interaction
- Computer automation
- File management
- Web browsing
- Vision
- Memory
- Autonomous task execution

## Tech Stack

- Python
- Ollama
- Qwen
- Whisper
- Piper
- Playwright
- PySide6
- SQLite
- ChromaDB
